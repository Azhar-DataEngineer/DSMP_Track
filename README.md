## Contents

This repository will hold notes, exercises, and small projects as the track progresses.

## Getting started

Clone the repo and open it in your editor:

```bash
git clone git@github.com:Azhar-DataEngineer/DSMP_Track.git
cd DSMP_Track
```

Use Python 3 for the exercises in this track.
